# 📄 CV Generator - Creador de Currículum Vitae

¡Bienvenido a **CV Generator**! Esta es una aplicación web responsiva y moderna diseñada para ayudar a los usuarios a crear, personalizar y visualizar su Currículum Vitae de forma rápida y sencilla, utilizando todo el potencial de **Bootstrap**.

---

## 🚀 Características

*   **Diseño Totalmente Responsivo:** Gracias a Bootstrap, la interfaz se adapta perfectamente a dispositivos móviles, tablets y ordenadores de escritorio.
*   **Plantillas Modernas:** Estilos limpios y profesionales que hacen que tu CV destaque.
*   **Secciones Dinámicas:** Incluye apartados para Experiencia Laboral, Educación, Habilidades (con barras de progreso), Idiomas y Contacto.
*   **Fácil de Personalizar:** Código estructurado y modular para que puedas añadir tus propios estilos o modificar la estructura en pocos minutos.
*   *Enlace para exportar a PDF (Opcional, bórralo si no lo usas).*

---

## 🛠️ Tecnologías Utilizadas

Las principales tecnologías y librerías utilizadas en este proyecto son:

*   **HTML5** - Estructura semántica de la web.
*   **CSS3** - Estilos personalizados adicionales.
*   **Bootstrap v5.3** (o la versión que uses) - Framework de CSS para el diseño ágil y el sistema de rejilla (Grid).
*   **FontAwesome** - Iconos vectoriales para las secciones de contacto y redes sociales.
